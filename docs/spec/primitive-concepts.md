# Primitive Concepts

## Purpose

This document explores the smallest possible set of concepts required to describe any adaptive change process.

No concept in this document is considered accepted.

Each candidate must justify its existence by representing a universal phenomenon that cannot be described by simpler concepts.

Primitive concepts should be:

- Universal
- Domain-independent
- Necessary
- Implementation-independent

Concepts that can be derived from more fundamental concepts should not be considered primitive.

---

## Candidate Concepts

The following concepts are currently being investigated.

Their inclusion does **not** imply acceptance.

| Concept | Status | Notes |
|---------|--------|-------|
| Current State | Candidate | Starting point of every adaptive process. |
| Desired State | Candidate | Direction of change. |
| Observation | Candidate | Represents new information about reality. |
| Decision | Candidate | Chooses between possible actions. |
| Action | Candidate | Intentionally changes the current state. |
| Outcome | Candidate | Result of one or more actions. |
