# Phenomena

This document describes observable phenomena that appear to exist in every adaptive change process.

These observations are implementation-independent and domain-independent.

---

## PH-001

Change always starts from a current situation.

Evidence

Every observed example begins somewhere.

Possible concepts

Current State

Status

Observed

## PH-002

Change always has direction.

Evidence
