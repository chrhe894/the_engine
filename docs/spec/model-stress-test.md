# Model Stress Test

## Purpose

The current working model is:

    Identity N
        │
        ├── Opportunities
        ├── Obstacles / Constraints
        ├── Motivation
        │
        ▼
    Transition
        │
        ▼
    Identity N+1
        │
        ▼
    Feedback / Observation
        │
        └──────────────→ next transition

The purpose of this document is to test whether this model is sufficiently
general to describe very different forms of adaptive change.

The objective is not to prove the model correct.

The objective is to discover phenomena that the model cannot adequately
represent.

A failure is therefore useful: it tells us where the model needs to evolve.

---

# Test Cases

## ST-001 — Individual Development

### Scenario

An 18-year-old newcomer to Sweden wants to become a software developer.

The person starts with limited programming experience, limited professional
network and limited knowledge of the Swedish professional environment.

The desired future Identity is a capable software developer who can work
independently and participate effectively in a professional environment.

### Questions

- What constitutes the Current Identity?
- Which Identity building blocks are relevant?
- What is the Desired Identity?
- Which building blocks need to change?
- Which Opportunities are available?
- Which Obstacles / Constraints exist?
- Which other identities can contribute?
- What Missions can induce useful Transitions?
- How does Motivation affect the size of the transition?
- What Feedback should be observed?
- Can several building blocks improve through one Mission?

### Expected observation

The model should be able to describe development as a sequence of
meaningful Identity transitions rather than as a fixed long-term plan.

## ST-002 — Multi-Actor Ecosystem

### Scenario

Ölands Skördefest wants to become a more attractive and distinctive event,
with more visitors and stronger participation from local businesses,
artists, cultural actors and other communities.

Potential identities include:

- Festival organisation
- Visitors
- Business owners
- Artists
- Painters
- Birdwatchers
- Associations
- Local communities
- Sponsors

### Questions

- Can different Identity types have completely different building blocks?
- Can one Opportunity connect several identities?
- Can matchmaking discover Opportunities?
- Can one Mission affect multiple identities?
- Can cooperation itself emerge as part of a Transition?
- Can the Festival's Identity change through transitions occurring between
  other identities?

### Expected observation

The model should support an ecosystem in which value is created through
relationships and matchmaking rather than through actions performed by a
single central actor.

## ST-003 — Organisational / District Transformation

### Scenario

A property company wants to increase the attractiveness of a district.

The property company cannot create the desired future alone.

Relevant identities may include:

- Property company
- Residents
- Local businesses
- Artists
- Associations
- Municipality
- Schools
- Visitors
- Other property owners

### Questions

- Can "district attractiveness" be represented as a Desired Identity?
- Can the Desired Identity be decomposed into relevant building blocks?
- Can opportunities emerge between identities?
- Can empty resources become Opportunities?
- Can a Mission change several identities simultaneously?
- Can a successful local transition create new Opportunities?
- Can the district itself be treated as an Identity?
- Can a collective Identity emerge that did not previously exist?

### Expected observation

The model should support emergent change where no single actor owns the
complete transition.

## ST-004 — Project Peace on Earth

### Scenario

The desired future is a world in which violent conflict is no longer a
persistent mechanism for resolving differences between human groups.

The system contains many interacting identities, including:

- Individuals
- Communities
- States
- Political organisations
- Military organisations
- Businesses
- NGOs
- Religious organisations
- International organisations
- Media
- Other groups and institutions

### Questions

- Can multiple identities have conflicting Desired Identities?
- Can one identity's desired transition obstruct another's?
- Can conflict be represented as an Obstacle / Constraint?
- Can normative constraints be represented?
- Can laws and regulations be represented without becoming primitive concepts?
- Can security needs and threat perceptions be represented?
- Can opportunities exist between adversarial identities?
- Can cooperation itself change Identity?
- Can the desired future change during the process?
- Can unintended consequences create new Obstacles?
- Can the system operate when the Desired Identity is only partially known?

### Expected observation

The model should support conflicting interests, multiple simultaneous
transitions, external constraints and emergent systemic change.

# Evaluation Criteria

For each case, record:

### 1. Coverage

Can the case be represented without adding a new primitive concept?

### 2. Identity

Can the relevant Identity be represented as a context-dependent
configuration of building blocks?

### 3. Transition

Can the actual mechanism of change be represented?

### 4. Opportunity

Can possibilities, cooperation and matchmaking be represented?

### 5. Constraints

Can obstacles, conflicting interests and external constraints be
represented?

### 6. Motivation

Can motivation influence the choice and size of transitions?

### 7. Multi-actor change

Can one transition affect multiple identities?

### 8. Feedback

Can observations from one transition influence the next transition?

### 9. Emergence

Can new capabilities, relationships or collective identities emerge?

### 10. Uncertainty

Can the model operate when the Desired Identity or path is incomplete
or changes during the process?

# Test Principle

Do not add a new primitive concept merely because a case is difficult.

First investigate whether the phenomenon can be represented as:

- an Identity building block,
- an Opportunity,
- an Obstacle / Constraint,
- a Motivation,
- a Transition,
- a Mission,
- or Feedback / Observation.

A new primitive concept should only be introduced when the existing model
cannot adequately represent a fundamental phenomenon.
