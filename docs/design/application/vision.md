# Application Vision

## Status

**Discovery / Prototype**

This application is the user-facing front end to the semantic system being
developed in parallel.

The application should help a person or group understand their current
situation, explore possible futures, choose a meaningful next transition and
learn from what happens.

The user should never need to understand the underlying information model.

## Core experience

The application should help answer:

1. **Where are we now?**
2. **What could we become?**
3. **What is worth pursuing next?**
4. **What happened, and what did we learn?**

The application should support movement through these questions rather than
presenting a complete solution.

## Product identity

The application is not primarily a project-management system, goal tracker,
workflow engine, dashboard, social network, or AI assistant. It may contain
elements of all of these.

Its primary identity is:

> **A system that helps people and organisations navigate meaningful
> transitions.**

## User authority

The system may observe, organise, connect, suggest, compare, project and ask
questions.

**The user decides.**

AI-generated suggestions and projections must remain distinguishable from
observed information and user decisions.

## Smallest useful next step

Prefer:

> **the next meaningful choice or transition**

over a complete plan for the entire journey.

## Multiple scales

The same experience should eventually support an individual, team, business,
organisation, several cooperating organisations, community, district, event,
or other collective Thing.

The interface should not require permanent classification into one category.

## Prototype hypothesis

A user should be able to enter with almost no pre-existing model of the
application and quickly reach a useful:

```text
current situation → possible directions → next choice → next transition
```

without a long onboarding process.
